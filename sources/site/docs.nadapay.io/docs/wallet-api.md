## 

Wallets vs. balances

[Skip link to Wallets vs. balances](https://docs.nadapay.io/docs/wallet-api#wallets-vs-balances)

A wallet is one ledger per currency. If your organization holds USD, NGN, and USDC, that's three separate wallets, each with its own ID, balance, and ledger.
