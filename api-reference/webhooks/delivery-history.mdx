---
title: 'GET /organization/webhooks/deliveries/history — View Delivery History'
sidebarTitle: 'Delivery History'
description: 'Retrieve paginated delivery attempt history for a webhook. Use this to debug failures, confirm deliveries, and inspect response codes.'
---

Every time NadaPay attempts to deliver an event to your webhook endpoint, it records the attempt — including the event type, HTTP response code your server returned, and whether the delivery succeeded or failed. Use this endpoint to audit delivery history, investigate failures, and identify whether a specific event was successfully received. Filter by `webhookId` to scope the history to a particular endpoint.

## Query parameters

<ParamField query="webhookId" type="string" required>
  The ID of the webhook whose delivery history you want to retrieve.
</ParamField>

<ParamField query="page" type="number" default="1">
  The page number to retrieve.
</ParamField>

<ParamField query="limit" type="number" default="10">
  The maximum number of delivery records to return per page.
</ParamField>

<ParamField query="sortBy" type="string" default="createdAt">
  The field to sort results by.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

```bash
curl --request GET \
  --url 'https://core.nadapay.io/api/v1/organization/webhooks/deliveries/history?webhookId=wh_abc123&page=1&limit=10' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

A `200` response returns an array of delivery attempt records.

<ResponseField name="data" type="array">
  Array of delivery attempt objects.
</ResponseField>

<ResponseField name="data[].id" type="string">
  Unique identifier for this delivery attempt. Use this ID to retry a failed delivery.
</ResponseField>

<ResponseField name="data[].webhookId" type="string">
  The webhook endpoint that received this delivery attempt.
</ResponseField>

<ResponseField name="data[].event" type="string">
  The event type that triggered this delivery, e.g. `TRANSACTION.COMPLETED`.
</ResponseField>

<ResponseField name="data[].status" type="string">
  Whether the delivery succeeded or failed: `SUCCESS` or `FAILED`.
</ResponseField>

<ResponseField name="data[].responseCode" type="number">
  The HTTP status code returned by your endpoint, e.g. `200`, `500`.
</ResponseField>

<ResponseField name="data[].timestamp" type="string">
  ISO 8601 timestamp of when the delivery was attempted.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata including `page`, `limit`, and `total`.
</ResponseField>
