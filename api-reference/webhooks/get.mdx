---
title: 'GET /organization/webhooks/:id — Get Webhook Details'
sidebarTitle: 'Get'
description: 'Fetch the full configuration of a single registered webhook endpoint by ID, including the subscribed events, current status, and target environment.'
---

Use this endpoint to retrieve the full configuration of a specific webhook — for example, to confirm which events it is subscribed to, verify its current status, or display endpoint details in a webhook management UI. The signing secret is not returned in this response; it is only available at the time of registration.

## Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the webhook to retrieve.
</ParamField>

```bash
curl --request GET \
  --url https://core.nadapay.io/api/v1/organization/webhooks/wh_abc123 \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

A `200` response returns the webhook configuration.

<ResponseField name="id" type="string">
  The webhook's unique identifier.
</ResponseField>

<ResponseField name="url" type="string">
  The registered delivery URL.
</ResponseField>

<ResponseField name="events" type="array">
  The event types this webhook subscribes to.
</ResponseField>

<ResponseField name="status" type="string">
  The current webhook status: `ACTIVE` or `INACTIVE`.
</ResponseField>

<ResponseField name="environment" type="string">
  The environment this webhook belongs to: `TEST` or `LIVE`.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

```json
{
  "success": true,
  "statusCode": 200,
  "message": "Webhook details retrieved successfully.",
  "data": {
    "id": "wh_abc123",
    "url": "https://yourapp.com/webhooks/nadapay",
    "events": ["TRANSACTION.COMPLETED", "TRANSACTION.FAILED"],
    "status": "ACTIVE",
    "environment": "LIVE",
    "createdAt": "2026-04-01T00:00:00.000Z"
  }
}
```

## Error codes

| Status | Meaning |
| --- | --- |
| `404` | No webhook found with the given `id`. |
