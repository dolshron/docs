---
title: 'GET /organization/payment-links — List Payment Links'
sidebarTitle: 'List'
description: 'Retrieve a paginated list of all payment links under your organization, with status, amount, currency, and creation timestamp for each link.'
---

This endpoint returns a paginated list of every payment link created under your organization. Use it to build dashboards, audit active links, locate a specific link's `id` for downstream operations, or integrate payment link management into your admin tooling. Each item in the response includes the link's unique identifier, shareable URL, amount, currency, active status, and creation timestamp. The endpoint supports standard pagination and sort parameters so you can work efficiently through large sets of links.

## Endpoint

```text
GET https://core.nadapay.io/api/v1/organization/payment-links
```

## Request Headers

| Header | Value |
|--------|-------|
| `x-api-key` | `YOUR_API_KEY` |

## Query Parameters

<ParamField query="page" type="number" default="1">
  Page number to retrieve. Starts at `1`.
</ParamField>

<ParamField query="limit" type="number" default="10">
  Number of payment links to return per page.
</ParamField>

<ParamField query="sortBy" type="string" default="createdAt">
  The field to sort results by. Defaults to `createdAt`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort direction. Allowed values: `asc`, `desc`.
</ParamField>

## Example Request

```bash
curl --request GET \
  --url 'https://core.nadapay.io/api/v1/organization/payment-links?page=1&limit=10&sortBy=createdAt&sortOrder=desc' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

<ResponseField name="success" type="boolean">
  `true` when the request completes successfully.
</ResponseField>

<ResponseField name="statusCode" type="number">
  HTTP status code — `200` on success.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable status, e.g. `"Payment links retrieved successfully"`.
</ResponseField>

<ResponseField name="data" type="object">
  Paginated result wrapper.

  <Expandable title="data fields">
    <ResponseField name="items" type="array">
      Array of payment link objects.

      <Expandable title="payment link object fields">
        <ResponseField name="id" type="string">
          Unique payment link identifier.
        </ResponseField>

        <ResponseField name="slug" type="string">
          URL slug used in the hosted payment page path.
        </ResponseField>

        <ResponseField name="url" type="string">
          The fully formed, shareable payment link URL.
        </ResponseField>

        <ResponseField name="amount" type="number">
          Fixed payment amount in the smallest currency unit. `null` for variable-amount links.
        </ResponseField>

        <ResponseField name="currency" type="string">
          ISO 4217 currency code.
        </ResponseField>

        <ResponseField name="isActive" type="boolean">
          `true` when the link is currently active and accepting payments.
        </ResponseField>

        <ResponseField name="createdAt" type="string">
          ISO 8601 timestamp of when the link was created.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="total" type="number">
      Total number of payment links across all pages.
    </ResponseField>

    <ResponseField name="page" type="number">
      The current page number returned.
    </ResponseField>

    <ResponseField name="limit" type="number">
      Number of results per page used for this response.
    </ResponseField>
  </Expandable>
</ResponseField>
