---
title: 'GET /organizations/accounts/:id/ledger — Get Account Ledger'
sidebarTitle: 'Ledger'
description: 'Retrieve paginated ledger entries for a specific account. Use this for reconciliation and audit trails — not for real-time settlement logic.'
---

The account ledger provides a chronological record of every credit and debit for a specific financial account. Use it for reconciliation, generating statements, or building an audit trail. Results are paginated and sorted by `createdAt` descending by default, so the most recent entries appear first. For real-time settlement logic, rely on webhooks rather than polling the ledger.

## Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the financial account whose ledger you want to retrieve.
</ParamField>

## Query parameters

<ParamField query="page" type="number" default="1">
  The page number to retrieve.
</ParamField>

<ParamField query="limit" type="number" default="10">
  The maximum number of ledger entries to return per page.
</ParamField>

<ParamField query="sortBy" type="string" default="createdAt">
  The field to sort entries by.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

```bash
curl --request GET \
  --url 'https://core.nadapay.io/api/v1/organizations/accounts/acc-uuid-123/ledger?page=1&limit=10&sortBy=createdAt&sortOrder=desc' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

A `200` response returns paginated ledger entries for the account.

<ResponseField name="data" type="array">
  Array of ledger entry objects. Each entry typically includes a transaction reference, amount, type (credit/debit), and timestamp.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata including `page`, `limit`, and `total`.
</ResponseField>
