---
title: "GET /beneficiaries/:id — Get Beneficiary Details"
sidebarTitle: "Get Beneficiary"
description: "Fetch complete details for a single beneficiary profile by ID, including contact information, destination type, and linked payout accounts."
---

Use this endpoint when you need the full details of a specific beneficiary — for example, to confirm the attached payout accounts before initiating a transaction, or to display recipient information in your application UI. You need the beneficiary's `id`, which is returned when you create a beneficiary or list all beneficiaries.

## Request

**GET** `https://core.nadapay.io/api/v1/beneficiaries/{id}`

```bash
curl --request GET \
  --url 'https://core.nadapay.io/api/v1/beneficiaries/ben_01HXXXXXXXXXXXXXXXXXX' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Request Headers

<ParamField header="x-api-key" type="string" required>
  Your NadaPay API key.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the beneficiary you want to retrieve. This is the `id` returned when the beneficiary was created.
</ParamField>

## Response

A successful `200 OK` response returns the full beneficiary profile, including any payout accounts attached to it.

```json
{
  "data": {
    "id": "ben_01HXXXXXXXXXXXXXXXXXX",
    "name": "Amara Diallo",
    "email": "amara.diallo@example.com",
    "phone": "+2348012345678",
    "type": "EXTERNAL_BANK",
    "status": "active",
    "currency": "NGN",
    "created_at": "2025-01-01T00:00:00Z",
    "updated_at": "2025-01-05T12:00:00Z",
    "accounts": [
      {
        "id": "acc_01HXXXXXXXXXXXXXXXXXX",
        "currency": "NGN",
        "type": "EXTERNAL_BANK",
        "status": "active",
        "details": {
          "accountNumber": "0123456789",
          "accountName": "Amara Diallo",
          "country": "NG"
        }
      }
    ]
  }
}
```

<ResponseField name="data.id" type="string">
  Unique identifier for the beneficiary.
</ResponseField>

<ResponseField name="data.name" type="string">
  Display name of the beneficiary.
</ResponseField>

<ResponseField name="data.email" type="string">
  Beneficiary email address, if provided at creation.
</ResponseField>

<ResponseField name="data.phone" type="string">
  Beneficiary phone number, if provided at creation.
</ResponseField>

<ResponseField name="data.type" type="string">
  Destination type: `INTERNAL`, `EXTERNAL_BANK`, or `EXTERNAL_WALLET`.
</ResponseField>

<ResponseField name="data.status" type="string">
  Current lifecycle status of the beneficiary, e.g. `active`, `inactive`.
</ResponseField>

<ResponseField name="data.currency" type="string">
  The payout currency this beneficiary is configured for.
</ResponseField>

<ResponseField name="data.created_at" type="string">
  ISO 8601 timestamp when the beneficiary was first created.
</ResponseField>

<ResponseField name="data.updated_at" type="string">
  ISO 8601 timestamp of the last update to this beneficiary profile.
</ResponseField>

<ResponseField name="data.accounts" type="array">
  Array of payout account objects attached to this beneficiary. Each account represents a specific destination such as a bank account, mobile money wallet, or crypto address.
</ResponseField>

<ResponseField name="data.accounts[].id" type="string">
  Unique identifier for the payout account. Use this when updating or deleting the account.
</ResponseField>

<ResponseField name="data.accounts[].currency" type="string">
  Currency this payout account transacts in.
</ResponseField>

<ResponseField name="data.accounts[].type" type="string">
  Account destination type.
</ResponseField>

<ResponseField name="data.accounts[].status" type="string">
  Current status of the payout account.
</ResponseField>

<ResponseField name="data.accounts[].details" type="object">
  Destination-specific fields such as `accountNumber`, `accountName`, `country`, `chain`, or `address`.
</ResponseField>
