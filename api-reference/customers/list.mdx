---
title: 'GET /organization/customers — List All Customers'
sidebarTitle: 'List'
description: 'Retrieve a paginated list of all customers in your organization, with optional sort field, sort direction, and configurable page size.'
---

Use this endpoint to fetch every customer you have created under your organization. Results are paginated and sorted by `createdAt` descending by default, so the most recently added customers appear first. You can adjust the page size and sort order to suit your UI or reconciliation workflow.

## Query parameters

<ParamField query="page" type="number" default="1">
  The page number to retrieve. Pages start at `1`.
</ParamField>

<ParamField query="limit" type="number" default="10">
  The maximum number of customers to return per page.
</ParamField>

<ParamField query="sortBy" type="string" default="createdAt">
  The field to sort results by.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort direction. Accepted values: `asc`, `desc`.
</ParamField>

```bash
curl --request GET \
  --url 'https://core.nadapay.io/api/v1/organization/customers?page=1&limit=10&sortBy=createdAt&sortOrder=desc' \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

A `200` response returns a paginated list of customer objects.

<ResponseField name="data" type="array">
  Array of customer records. Each item contains `id`, `name`, `email`, `phone`, and `createdAt`.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata including `page`, `limit`, and `total`.
</ResponseField>

```json
{
  "success": true,

  "message": "Customers retrieved successfully",
```
