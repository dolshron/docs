---
title: 'DELETE /organization/customers/:id — Delete a Customer'
sidebarTitle: 'Delete'
description: 'Permanently delete a customer record from your organization. This action cannot be undone — verify the ID before you call this endpoint.'
---

Deleting a customer permanently removes their record from your organization. Before calling this endpoint, make sure you no longer need the customer's profile for active invoices or historical reporting. If the customer has open invoices, consider cancelling those first.

## Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the customer to delete.
</ParamField>

```bash
curl --request DELETE \
  --url https://core.nadapay.io/api/v1/organization/customers/cus_abc123 \
  --header 'x-api-key: YOUR_API_KEY'
```

## Response

A `200` response confirms the customer was deleted.

```json
{
  "success": true,
  "statusCode": 200,
  "message": "Customer deleted successfully"
}
```

## Error codes

| Status | Meaning |
| --- | --- |
| `404` | No customer found with the given `id` in your organization. |
